---
name: video-generation
description: Generate MiniMax H3 storyboard clips with native stereo audio and assemble them into a playable proof-of-concept reel.
---

1. Call `get_project_capabilities` first. Use a ready `video` provider and a supported mode (`fl2va` or `ref2va`). Readiness is a preflight, not an inference result. Never start or reconfigure ComfyUI or generate during a discussion-only storyboard pitch.
2. Choose the conditioning mode and use ready image artefacts:
   - **`fl2va` (default, storyboard to video):** set `first_frame_artifact_id` to the opening panel. Optionally add `last_frame_artifact_id` for the closing panel and up to four intermediate `guide_frames` (`{artifact_id, frame_index}`) at distinct zero-based indices for key motion beats.
   - **`ref2va` (character and world consistency):** supply up to nine ordered `reference_artifact_ids`. Tag them as `<Picture 1>`, `<Picture 2>`, and so on in the exact input order. Optionally anchor the opening with `first_frame_artifact_id` (`frame_idx = 0`). Keep `ref_image_size: "match"` for fast proofs. Use `"max"` only when finer identity detail justifies slower steps.
3. Prompt for motion and sound together. Describe the camera move, subject action, lighting continuity and soundscape, music or dialogue. MiniMax H3 generates video and stereo audio jointly. Specify “ambient sound and music only” or “silent” when appropriate. For guaranteed silence in the export, use a silent sequence.
4. Call `prepare_video_generation` with a fresh `operation_id`, prompt, JSON-safe decimal string seed (`<= 9007199254740991`), `mode` and `duration_seconds` (`1..15`). H3 snaps to its 24 fps `17k + 5` grid: 5 s → 124 frames, 10 s → 243, 15 s → 362. Omit `width`, `height` and `steps` for the fast recipe defaults (864×480, four-step Turbo LoRA on the standard recipe). For an FL2VA hero proof, request 1344×768 and `steps: 8` if available. Dimensions must be multiples of 32 within the provider pixel limit (at most `1344 × 768` pixels in total). Omit `project_id` and `generation_task_id`; the host supplies them.
5. Call `submit_generation` with the exact returned `submit_request`. Wait with `get_job(job_id=..., wait_seconds=15)`. Inspect the verified MP4 artefact for dimensions, frame count, duration and audio. When appropriate and a visual reviewer is available, register extracted frames as image artefacts and call `request_vlm_review` before choosing clips for the cut.
6. For a storyboard proof-of-concept reel, author a clip-only `SequenceMap` using `SequenceClipEntry`. Set `clip_artifact_id`, `source_frames` and `sequence_frames` (one-based inclusive ranges), `transform: "identity"` or `"trim"`, and `mapping_artifact_id: null`. Use a consistent frame rate and contiguous sequence ranges. Set `silent: false` and `preserve_clip_audio: true` to retain each shot's stereo audio. Optionally layer `audio_tracks`, such as a Stable Audio 3 underscore. For a silent reel use `silent: true` and omit tracks and `preserve_clip_audio`. Run `validate_authored_document` with `document_kind: "sequence_map"`, checkpoint and publish the sequence, then call `assemble_sequence` for its exact published version.

On ROCm 10.1 / Strix Halo, the host recipe uses AMD-compatible `int8_convrot` weights and keeps the audio VAE in FP32. It inserts `VAEComputeDtype` (`bf16`) for the video VAE only when ComfyUI `/object_info` advertises compatible BF16 support. Provider readiness alone does not confirm BF16 wrapping. The host automatically requires tiled video VAE decode above `864 × 480` pixels or 124 frames.
