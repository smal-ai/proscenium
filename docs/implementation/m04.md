The oracle decodes the actual GLB vertex accessor and resolves both authored instance mappings. It selects each cube's far top edge and asserts that its endpoints exist in the mesh. Proxy-world vertices convert to Blender-world metres and project through the accepted captured pose/projection. For each edge, 17 fixed lanes at fractions 0.2–0.8 measure bilinear blue-minus-red half-step crossings against the neutral surrounding geometry. The reported difference is the difference of the two images' median signed normal offsets. Every lane and projected endpoint is retained in `framing-measurements.json`.

Native offsets from the geometric projection have median absolute values below 0.177 px. The maximum absolute native individual-lane offset is 0.436 px. This is measured mesh/raster correspondence, not whole-image colour equality. Static inspection lighting and native Cycles lighting intentionally differ.

Both native profiles are Blender **4.5.14 LTS**, build `62c1db4208e8`, Cycles **CPU**, **8 samples**, **4 threads**, PNG RGB8 with baked view-transformed sRGB, Standard/None/0/1.
