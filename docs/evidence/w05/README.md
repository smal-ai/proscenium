# W05 evidence

Scope: actual feature code under an isolated, synthetic HTTP/database harness.
This is not integrated application, native rendering or model-service acceptance.

- `browser-result.json` is generated by the committed Playwright reporter. It
  records each actual browser result, exact fixture-manifest hashes and raw
  rVFC/canvas ordinal-cell observations at both rates. Attachments include engine
  versions and callback gaps at `4→5` and `8→9`. The source media is the accepted
  E03 F03/F04 numbered **synthetic derivative**, reused without native regeneration.
- `synthetic-surfaces-1920x1080.png` captures the isolated review/outliner/critic
  composition, not the integrated W04 shell or a real user's project.
- `checks.json` records exact commands, results, source baseline and limitations.

Browser replay:

```bash
npx playwright test --config tests/browser/review.config.ts \
  --reporter=line,./tests/browser/review-reporter.cjs
```

The E03 fixture directory must already exist at
`/tmp/opencode/proscenium-e03-20261114-a`. The browser suite does not render, encode,
install browsers, start model services or touch reference/user projects. All
browser profiles are disposable. Installed Brave and Edge run sequentially after
the pinned Chromium project. Chromium DPR 2 repeats the same actual pointer/media
checks. Only the Vite harness process is started and stopped by Playwright.

The suite asserts each decoded ordinal **once**, no black/unknown ordinal, exact
local PTS correspondence, no skipping a withheld middle interval, paused target
stability, form-keyboard isolation, exact instance pairs, durable original save
retry, explicit conflict rebase, canonical mask upload, selected-finding submission
and explicit external target navigation. Boundary callback gaps are measured,
not relabelled as zero-latency playback. Desktop compositing/performance and
integrated producer-to-player timing remain separate acceptance work.
